Onboarding

3 步，开始用你的 AI

1
STEP 1

AI 设置

SQL Integration

用 SuDu 同步工具安全连接 SQL Account。顾客、货品、价格、库存和信用额度自动同步，不直接写进你的数据库。

  • 连接 SQL Account
  • 同步顾客、货品和价格
  • 设好权限和批准人
2
STEP 2

训练 AI

Skill / SOP · Item Code

像教新员工一样，把你的做法写成 Skill 和 SOP。再教它顾客的叫法：“bwg besar” 就是你系统里的哪个 item code。

  • 写下 Skill 和 SOP
  • 对上 item code
  • 用上个月的订单测试
3
STEP 3

开始用你的 AI

Go Live

AI 开始接单、追款、查库存、做报表。一开始只出草稿，你批准了才保存。信任建立后，再一个一个加工作。

  • 先出草稿，你来批准
  • 每个动作都有记录
  • 一次加一个工作
